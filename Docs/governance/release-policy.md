# Release Policy & Release Candidate Quality Gates

## Milestone Roadmap to v1.0 Launch

- **Milestone 0.1**: Platform Runtime, Mission Runtime, JWT Reference Implementation (✅ Complete).
- **Milestone 0.2**: SDK Suite, Capability Fabric, Mission Harness, Examples (✅ Complete).
- **Milestone 0.3 — Developer Preview 1 (DP1)**: Architecture Frozen (ADR-0001), Governance Locked, CI Pipeline Configured (✅ Current Stage).
- **Milestone 0.4**: Execution of Feature Board (RI-002 through RI-010 Reference Implementations & Benchmarks).
- **Release Candidate (RC1)**: 100% of RI-001 through RI-010 Reference Suite verified and passing.
- **v1.0 Launch**: Stable Contracts, Complete Documentation, Public Launch on GitHub & Hugging Face.

---

## Release Candidate Verification Gate
A release candidate is approved ONLY if 100% of the Reference Implementation Suite passes:
- **RI-001**: JWT Authentication
- **RI-002**: CRUD REST API
- **RI-003**: Blog Platform
- **RI-004**: OAuth Login
- **RI-005**: Payment Integration
- **RI-006**: Kubernetes Deployment
- **RI-007**: Bug Fix & Provenance
- **RI-008**: Large Refactor (Temporal Durability)
- **RI-009**: Browser Automation
- **RI-010**: Multi-Repository Upgrade
